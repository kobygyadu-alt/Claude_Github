How to refresh this dashboard (monthly, ~2 minutes)
  1. Open the PV workbook → sheet 📤 Dashboard Extract.
  2. File → Save As (or Export) → CSV UTF-8 → save as dashboard_extract.csv. (Only the active sheet is exported — make sure the extract sheet is selected.)
  3. Open this dashboard and click Load data (CSV) (or drag the file onto the page).
Assumptions: dates are read as ISO (2026-01-14), day-first (14/01/2026) or Excel serial numbers; ambiguous dates are treated day-first (Ghana locale). Financial year = calendar year (⚙️ Settings: FY starts January). Loaded data stays in your browser only.
